# 第三次 Learning Agent 提交说明

这是课程材料的 GitHub 源码版，2026-11-12 同步。保留原训练代码、两页报告、权重和唯一实验记录；课程 ZIP、本机复检日志和重复证据文件不再重复上传。下文所说的课程 ZIP 是另外准备的提交材料，不是本仓库的完整下载压缩包。仓库还保留旧二维原型。

一句话：基于组员上次的环境和神经网络，把“可以演示一次 PPO 更新”的代码，做成一套能持续训练、检查学习过程、保存模型并独立评估的强化学习框架。

## 相对上次提交，最需要强调的进步

**上次环境已经记录实际有序航点到达数，但网络看不到；这次把它作为“已完成航点比例 c/N”提供给 Actor/Critic，并增加下一个未完成航点的相对位置。** 例如漏掉 B、reference 已到 C 时，新输入仍明确 B 尚未完成。这是任务信息上的改进，不是增加航点数量或放宽过关条件。

同时，训练奖励更强调实际到达和任务完成。reference 本身依然按时间推进，漏点目标与定时跟踪的冲突没有彻底消除；成功率提高来自多项改动的组合，不能全部归功于这个输入。

## 本次具体做了什么

1. **接上完整训练流程。** 环境采样、PPO 更新、验证、模型保存、reward 日志和曲线都已接通，不再只是网络前向和一次更新演示。
2. **补足任务信息。** 原来 15 维观测扩展到 23 维，加入参考速度误差、下一个未完成航点误差、航点进度和剩余时间。四维动作沿用推力偏差、滚转、俯仰和偏航角速度。真实风和液体质量仍不直接给策略。
3. **尝试更容易学到任务的训练方式。** 调整训练奖励，加入课程训练和动作保持；成功路线是先用 PPO 学粗跟踪，再用 PPO 学任务完成。没有使用 PID 示范、模仿学习损失或模仿训练权重。
4. **分开训练与考试。** 训练可以有辅助起点和奖励；评估仍按原始起点、完整风扰、全部十个有序航点、0.5 米三维容差和 45 秒限制进行，不放宽成功标准。
5. **准备可复现的交付。** 包含解释设计原因的注释、统一入口和配置、准确的 environment.yml、README、36 项通过的测试、两页共享报告、权重、真实训练日志与评估记录。

本轮额外补充了核心训练代码的注释和三个针对性测试；没有改动训练逻辑、参数、模型权重或既有实验数据。结果总览见 `results/RESULTS_SUMMARY.md`，其中完成率、航点数、轨迹误差、原始评估回报分开列出；两张新图分别展示“完成率与误差”和“训练奖励与原始奖励”。

## 现在能说明什么

这套框架能实际训练并产出结果；已有一个纯 PPO 两阶段模型在 50 个测试种子中完成 50 次。但另一个续训种子为 36/50，直接从零训练的变体为 0/50。调优传统控制器同样完成 50/50，而且轨迹 RMSE 更低。

因此本次合适的结论是“已有可运行、有学习进展的 agent 框架，下一步改善训练稳定性和跟踪质量”，不是“所有训练都稳定成功”或“PPO 已经胜过 PID”。两次续训共用一个基础模型，不是两次完全独立的从零训练。
