## 接手顺序

先按 README 安装或迁移，再执行版本检查、pip check、pytest 和
`python -m tools.verify_submission`。然后运行 CPU demo、三回合模型评估。
新实验用新输出目录，不覆盖已有数据。历史数据和本轮复检分开记录。

成功模型为两阶段 PPO：先训练 15 维基础控制，再接 23 维任务续训。新增“已完成
航点比例”和“下一个未完成航点误差”等输入，不是新增航点或放宽成功条件。
底层沿用姿态 PD，不是用 PID 专家动作做模仿学习。四维输出为推力偏差、滚转、
俯仰和偏航角速度命令。Critic 用于训练评价，不在动作输入里。

## 汇报结果保留边界

历史选择模型 50/50；另一续训种子 36/50，直接随机初始化 0/50。两次续训共用
同一基础模型，不是两次独立从零训练。额外十种子检查 9/10，一次漏点超时；
强风 17/20。调优传统控制同样 50/50 且 RMSE 更低，不能说 PPO 已胜过强 PID，
也不能把有限样本说成任何情况下都 100% 成功。

reference 仍按时间推进，漏点后返回与跟踪 reference 的冲突未全部解决。
喷洒沉积、真实能耗、换路线泛化和真实飞行安全未证明。复现已发表种子不能冒充
新的独立测试，短训练通过也不等于可靠收敛。
